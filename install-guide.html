字体变形-丹

Figma 文字转矢量与字体变形插件。本文档包含安装、使用、导出和常见问题说明。

当前版本 v5.2.0

一、安装插件

1

下载项目 ZIP，并解压到一个固定文件夹。建议文件夹路径只使用英文和数字，例如 D:\figma-type-warp-dan。

2

打开 Figma 桌面端，进入一个具有编辑权限的 Design 文件。

3

打开菜单 Plugins → Development → Import plugin from manifest…。

4

进入解压后的项目文件夹，选择根目录中的 manifest.json。

5

在画布中选中一个文字图层，打开 Plugins → Development → 字体变形-丹。

如果之前安装过旧版，请先关闭旧插件，再从新版文件夹重新导入 manifest.json，避免 Figma 继续运行旧目录中的代码。

二、基本使用

01 选择文字在画布中选中 TEXT 图层
02 选择形状点击右侧变形效果
03 调整预览拖动四角或修改强度
04 导出生成可编辑矢量

调整方式

  • 右侧选择上拱、下弧、外鼓、内收、波浪、飘旗、斜切或透视。
  • 使用“自定义”可以拖动 5 个曲线控制点。
  • 左侧预览区的四角控制点可以进行自由微调。
  • 预览不会修改画布中的原文字。

导出结果

点击“导出矢量字到画布”后，插件会在原文字右侧创建独立矢量图层。矢量图层可以在 Figma 中继续移动、缩放和编辑。

默认保留原文字；勾选“导出后隐藏原文字”可以隐藏原文字，但不会删除它。点击“恢复原始字体”可以再次显示原文字。

三、常见问题

导出按钮没有反应

  1. 确认画布中当前选中的是文字图层，而不是已经转好的矢量。
  2. 关闭插件后，重新点击画布中的原始文字，再打开插件。
  3. 确认使用的是 v5.2.0，并从新版文件夹重新导入 manifest.json。
  4. 组件实例内部文字暂不支持，请先复制到普通画布。

提示“请重新选择原始文字后再导出”

请先关闭插件，再在画布中重新点击原始文字图层，然后重新打开插件。不要只点击插件左侧预览中的文字。

导出后找不到矢量

结果默认放在原文字右侧，并且保持在原文字的同级父级中。可以在图层面板中查找名称带“（矢量）”的图层。

哪些情况暂不支持？

当前版本一次处理一个普通文字图层，不支持组件实例内部的文字；插件需要在 Figma 桌面端的可编辑 Design 文件中运行。

四、开发与测试

本项目不依赖第三方 npm 包。项目根目录提供 package.json，可运行：

npm run check
npm test

测试文件位于 tests/test-harness.js，用于验证变形、连续导出、自动布局、临时节点清理和选区状态恢复。
